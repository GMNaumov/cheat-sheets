# Промпт для разработки Python REST API

Ты — senior Python-разработчик. Помоги решить задачу.

## Контекст

- Python 3.11, FastAPI, SQLAlchemy, PostgreSQL.
- Небольшой REST API.
- Есть модель `User`: `id`, `email`, `password_hash`, `created_at`.

## Задача

Добавь endpoint `POST /users` для регистрации пользователя.

## Требования

- Валидировать и нормализовать email перед проверкой и сохранением.
- Требовать пароль длиной не менее 12 символов.
- Проверять уникальность email и добавить соответствующее ограничение на уровне PostgreSQL.
- Обрабатывать гонку одновременных регистраций через ошибку нарушения уникальности БД, а не только предварительный `SELECT`.
- Хешировать пароль через passlib/bcrypt.
- Возвращать `201` и данные пользователя без `password_hash`.
- При дубликате email возвращать `409`.

## Ограничения

- Не изменять существующие поля модели; при необходимости можно добавлять новые.
- Использовать Pydantic-схемы.
- Код должен быть асинхронным.

## Тесты

- Успешная регистрация пользователя.
- Отклонение некорректных email и короткого пароля.
- Отклонение повторной регистрации с тем же email.
- Обработка конкурентных запросов с одинаковым email.

## Формат ответа

План, код по файлам, пример запроса, тесты.
Если не хватает данных — задай вопросы.
