# Python-клиент Ollama

Пример запускает Ollama и одноразовый Python-клиент. При первом запуске клиент автоматически загрузит модель `qwen3:4b`, поэтому выполнение займёт больше времени и потребует подключения к интернету.

## Перед началом

Нужны Docker с Compose и свободное место для образов Ollama и Python, а также для модели `qwen3:4b`.

## Запуск

Выполните команду в каталоге примера:

```bash
docker compose run --rm client
```

Для другой модели измените `OLLAMA_MODEL` в `compose.yaml`.

После загрузки модели клиент отправляет тестовый запрос и выводит ответ модели в терминал.

## Проверка состояния

Если клиент завершился с ошибкой, проверьте состояние Ollama и её последние сообщения:

```bash
docker compose ps
docker compose logs --tail=100 ollama
```

## Остановка

Останавливает окружение Ollama после работы клиента. Загруженные модели сохраняются в именованном томе.

```bash
docker compose down
```

## Удаление данных

Следующая команда безвозвратно удалит том с загруженными моделями. Пропустите этот шаг, если модели нужны для повторного запуска.

```bash
docker compose down --volumes
```
