# Ollama через Docker Compose

Пример запускает Ollama с ограничениями ресурсов и хранит загруженные модели в именованном томе.

## Перед началом

Нужны Docker с Compose, подключение к интернету и свободное место для образа Ollama и модели `qwen3:4b`.

В `compose.yaml` установлены лимиты `7 CPU` и `20 GB` памяти, а также резервирование `4 GB`. Это параметры ограничения ресурсов, а не минимальные требования к компьютеру. При необходимости измените их в секции `deploy.resources` в соответствии с оборудованием. Для запуска модели требуется больше памяти, чем занимают её файлы на диске.

## Запуск

Выполните команды в каталоге примера:

```bash
docker compose up -d
docker compose exec ollama ollama pull qwen3:4b
docker compose exec ollama ollama list
```

API доступен только на локальном интерфейсе по адресу `http://localhost:11434`.

## Остановка

Данные в именованном томе сохранятся после остановки.

```bash
docker compose down
```

## Удаление данных

Следующая команда безвозвратно удалит том Ollama вместе со всеми загруженными моделями. Пропустите этот шаг, если модели нужны для повторного запуска.

```bash
docker compose down --volumes
```
