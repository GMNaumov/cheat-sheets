# Рабочий каталог DeepSeek Harness

Содержимое этого каталога подключено к DSH как `/workspace` с правом записи. При создании Workspace в DSH выберите путь `/workspace`.

Агент может создавать, изменять и удалять файлы в этом каталоге. Размещайте здесь только файлы задачи, с которыми разрешено работать агенту; изменения сразу видны на хосте. Для важных файлов используйте отдельный репозиторий или резервные копии.

Локальные рабочие файлы исключены из Git через [правила каталога](.gitignore). Они сохраняются после `docker compose down --volumes`, поскольку находятся на хосте.
