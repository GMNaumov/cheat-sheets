# Исходники .NET-проектов

Рабочий каталог подключается к контейнеру SDK как `/app`. Команды создания и сборки проектов записывают файлы сюда, поэтому изменения сразу видны на хосте.

Порядок работы описан в [инструкции примера](../README.md). Локальные проекты, включая `bin` и `obj`, исключены из Git через [правила каталога](.gitignore). Для хранения важных исходников используйте отдельный репозиторий или резервные копии.

Исходники сохраняются после `docker compose down --volumes`: эта команда удаляет том кэша NuGet, но не каталог на хосте.
