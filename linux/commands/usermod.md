# `usermod`

`usermod` изменяет параметры существующей учётной записи пользователя.

В этой заметке рассматривается добавление пользователя в дополнительную группу без изменения остальных групп.

## Добавить текущего пользователя в группу Docker

Флаги `-aG` добавляют группу, не удаляя пользователя из остальных дополнительных групп. Группа `docker` предоставляет привилегии уровня `root`; добавляйте в неё только доверенных пользователей.

```bash
sudo usermod -aG docker "$USER"
```

Выйдите из сеанса и войдите снова, чтобы применить членство в группе. Проверить список групп можно командой `groups`.
