# `cp`

`cp` (copy) копирует файлы и каталоги. Исходные файлы остаются на месте.

Последний аргумент задаёт назначение. По умолчанию существующий файл назначения перезаписывается без подтверждения.

## Скопировать файл под новым именем

```bash
cp config.example.yaml config.yaml
```

## Скопировать файлы в каталог

Каталог назначения должен существовать. Имена файлов сохраняются.

```bash
cp report.txt notes.txt ~/Documents/
```

## Запросить подтверждение перед перезаписью

Флаг `-i` запрашивает подтверждение, если файл назначения уже существует.

```bash
cp -i config.example.yaml config.yaml
```

## Скопировать каталог со всем содержимым

Флаг `-r` копирует каталог рекурсивно, включая вложенные каталоги и скрытые файлы.

```bash
cp -r project project-copy
```

Если `project-copy` не существует, он будет создан как копия `project`. Если уже существует как каталог, копия окажется в `project-copy/project`.

## Скопировать содержимое каталога с сохранением атрибутов

Флаг `-a` рекурсивно копирует содержимое, сохраняет символические ссылки как ссылки и по возможности сохраняет атрибуты: права, владельца и временные метки. Для сохранения чужого владельца могут потребоваться права `root`.

```bash
cp -a project/. project-backup/
```

Запись `project/.` копирует содержимое, включая скрытые файлы, прямо в `project-backup`, без дополнительного уровня `project`. При повторном копировании файлы назначения могут перезаписываться; файлы, отсутствующие в источнике, не удаляются.

## Показать, какие файлы копируются

Флаг `-v` выводит имена копируемых файлов. Его можно сочетать с другими флагами.

```bash
cp -iv report.txt ~/Documents/
```
