# `su`

`su` (substitute user) запускает оболочку или отдельную команду от имени другого пользователя. Если имя не указано, используется `root`.

Обычно требуется пароль целевого пользователя, а не текущего. Пользователь `root` обычно может переключаться без пароля; доступ также зависит от настроек системы.

## Переключиться на другого пользователя

Дефис `-` запускает оболочку входа: загружает окружение целевого пользователя и переходит в его домашний каталог. Замените `alice` на нужное имя пользователя.

```bash
su - alice
```

## Переключиться на root

Потребуется пароль `root`. Все последующие команды в этой оболочке выполняются с правами `root` до выхода из неё.

```bash
su -
```

Если вход под `root` заблокирован, как часто бывает в Ubuntu, используйте `sudo -i` при наличии разрешения на `sudo`. В этом случае обычно вводится пароль текущего пользователя.

## Переключиться без перехода в домашний каталог

Без `-` текущий каталог сохраняется, а окружение обновляется лишь частично. Для обычной работы с окружением целевого пользователя используйте `su - alice`.

```bash
su alice
```

## Выполнить одну команду от имени другого пользователя

Флаг `-c` передаёт команду оболочке целевого пользователя. После выполнения управление возвращается в исходную оболочку.

```bash
su - alice -c 'whoami'
```

Одинарные кавычки не дают текущей оболочке раскрывать переменные в строке команды. Например, `$HOME` в следующем примере относится к целевому пользователю.

```bash
su - alice -c 'ls -la "$HOME"'
```

## Вернуться в исходную оболочку

Завершите оболочку, запущенную через `su`, командой `exit` или сочетанием `Ctrl+D`.

```bash
exit
```
