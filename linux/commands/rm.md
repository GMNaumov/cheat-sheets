# `rm`

`rm` (remove) удаляет файлы и каталоги.

Удаление через `rm` не отправляет данные в корзину. Перед запуском проверяйте путь; относительные пути отсчитываются от текущего каталога, который можно узнать командой `pwd`.

## Удалить файл

Для обычного файла, доступного на запись, подтверждение по умолчанию не запрашивается.

```bash
rm old-report.txt
```

## Удалить несколько файлов

Перечислите имена через пробел. Все указанные файлы будут удалены.

```bash
rm old-report.txt old-notes.txt
```

## Запросить подтверждение перед удалением

Флаг `-i` запрашивает подтверждение для каждого файла.

```bash
rm -i old-report.txt
```

## Удалить каталог со всем содержимым

Флаг `-r` рекурсивно удаляет каталог, включая скрытые файлы и вложенные каталоги. В сочетании с `-i` команда запрашивает подтверждения при обходе и удалении.

```bash
rm -ri old-project/
```

Для удаления только пустого каталога можно использовать `rmdir old-project`.

## Удалить каталог без подтверждений

Флаги `-rf` удаляют каталог со всем содержимым без запросов подтверждения и не сообщают об отсутствующих файлах. Перед запуском проверьте путь: восстановление средствами `rm` невозможно. Флаг `-f` не обходит права доступа.

```bash
rm -rf build/
```

## Удалить файл, имя которого начинается с дефиса

Разделитель `--` завершает разбор флагов. Следующий аргумент воспринимается как имя файла; `-i` сохраняет запрос подтверждения.

```bash
rm -i -- -draft.txt
```
